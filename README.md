# Card Draw  

## Overview
Console based card game were each player competes to draw the closest to the target value in a declared amount of cards. The value of each card is random
## Tech Stack
- Java 21

## Features
-Automated Simulations
-Play against bots
-Game Summaries
-Leaderboards
-PvPvB


## What I Learned
-How to simulate other players
-Better implamentation of arrays


## How to Run
Simply run in an IDE to play!
